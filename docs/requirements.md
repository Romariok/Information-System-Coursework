# Предметная область, требования и прецеденты

## Предметная область

Сервис по подбору гитар и оборудования. Пользователь с разным опытом в сфере гитар может получить рекомендации по выбору нужной модели и оборудования к ней. В поиске учитываются не только базовые параметры (цена, материал, форма), но и то, какие модели использовали популярные исполнители в своих жанрах. В сервисе есть база данных исполнителей с подтверждающими материалами, а для всех моделей — статьи и обзоры от других пользователей.

---

## Задачи системы

1. Предоставить пользователям достаточное количество фильтров для поиска
2. Предоставить достаточно информации по каждой модели
3. Предоставить возможность писать статьи по каждой модели
4. Предоставить пользователям доступ к базе данных оборудования исполнителей
5. Предоставить возможность обновлять базу данных исполнителей

---

## Функциональные требования

### Авторизация

- Пользователи могут создавать учётную запись и авторизоваться.
- Авторизованные пользователи могут сбрасывать пароль.
- Система разделяет три класса доступа: неавторизованный пользователь, авторизованный пользователь, администратор.

### Неавторизованный пользователь

- Поиск гитары через фильтры и строку поиска.
- Чтение статей.
- Просмотр подробной информации по продукту.

### Авторизованный пользователь

Всё из предыдущего пункта, плюс:

- Создание статьи и привязка её к конкретному продукту.

### Администратор

Всё из предыдущего пункта, плюс:

- Одобрение статей, написанных пользователями.
- Одобренная статья появляется в списке и становится доступна для поиска.

### Поиск и фильтрация

- Фильтрация использует все основные атрибуты продукта.
- Поиск продуктов по имени исполнителя.

### Карточка продукта

- Отображается подробная информация: фотография, основные характеристики, описание, ссылки на статьи.

---

## Нефункциональные требования

- Время отклика не больше 2 секунд.

## Основные прецеденты

### Прецедент 1 — Новичок ищет рекомендации

| | |
|---|---|
| ID | 1 |
| Краткое описание | Поиск рекомендаций по выбору гитары и оборудования |
| Главный актёр | Неопытный пользователь |
| Второстепенный актёр | Система рекомендаций |
| Предусловия | Пользователь на главной странице |

Основной поток:
1. Пользователь выбирает раздел «Советы по выбору»
2. Система отображает список статей с рекомендациями
3. Пользователь выбирает интересующую статью
4. Система отображает содержание статьи
5. Пользователь переходит по ссылкам на рекомендуемые товары

| | |
|---|---|

| Главный актёр | Пользователь-автор |
| Второстепенный актёр | Модератор |
